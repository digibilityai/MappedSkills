# Internal Linking Best Practices - MappedSkills

## Overview
This guide covers internal linking strategy to improve SEO, user experience, and conversion rates across the MappedSkills website.

---

## A. Internal Linking Principles

### 1. Link Depth & Hierarchy
- **Level 1 (Homepage):** All pages should be 1-2 clicks from homepage
- **Service Pages:** Link to related services (Google Ads → Social Ads, etc.)
- **Blog Posts:** Link to relevant service pages in article body

### 2. Link Anchor Text Strategy
**Good Practice:**
- Descriptive anchor text: "Learn more about Google Ads management"
- Keyword-rich: "Google Ads optimization services"
- Partial match: "Our SEO services"

**Avoid:**
- "Click here" - Non-descriptive
- Bare URLs - "https://mappedskills.com/seo"
- Over-optimization - Exact match keyword repetition

### 3. Link Relevance & Context
- Link to pages that actually help the user
- Never link to unrelated pages for SEO benefit
- Consider user journey when placing links
- Ensure link text matches page topic

### 4. Internal Link Velocity
- Don't link excessively (max 5-7 internal links per page)
- Prioritize most important links (above the fold)
- Secondary links can appear in footer or sidebar

## B. Service Page Linking Structure

### Primary Service Pages
Link between services based on how they complement each other:

```
Google Ads ←→ Social Media Ads
    ↓            ↓
Lead Generation  Conversion Optimization
    ↓            ↓
    SEO ←────────┘
```

### Service Cross-Links
Example: In Google Ads page:
- "Improve campaign quality → Conversion Optimization"
- "Generate more qualified leads → Lead Generation"
- "Increase organic visibility → SEO"
- "Maximize social reach → Social Media Ads"

### Linking Strategy
1. **Navigation:** Main menu links to all service pages
2. **Service Pages:** Each service page links to 2-3 complementary services
3. **Comparison Sections:** "Google Ads vs other solutions" links to comparison page
4. **CTA Sections:** Final CTA might link to different services based on context

## C. Blog Post Linking (High Priority)

### Link to Service Pages
Each blog post should link to 1-2 relevant service pages:

| Blog Post | Internal Links |
|-----------|-----------------|
| "Google Ads ROI" | /google-ads, /conversion-optimization |
| "Facebook Ads Not Working" | /social-media-ads, /lead-generation |
| "SEO vs PPC" | /seo, /google-ads |
| "Lead Gen Strategy" | /lead-generation, /services |
| "CRO Guide" | /conversion-optimization, /pricing |

### Link Placement in Blog
1. **First mention** of service: Link to service page
2. **Natural context only:** Never force links
3. **Related posts:** Link to other relevant blog posts at end

### Blog-to-Blog Linking
- Related article links at end of post
- "Read next" section with 2-3 related articles
- Internal link in article body (1-2 contextual links max)

## G. Avoid These Mistakes

### ❌ Do NOT:
1. Link to the same page multiple times with different anchor text
2. Link to irrelevant pages for SEO benefit
3. Create link networks (A→B→C→A cycles)
4. Use "click here" for important links
5. Link on every instance of a keyword (once per page)
6. Add excessive internal links (>7-10 per page)
7. Link from low-quality pages to high-priority pages
8. Use no-follow on all internal links (defeats purpose)
9. Link to 404 pages
10. Forget mobile internal linking

### ✅ DO:
1. Link naturally where context supports it
2. Link from high-authority pages to less-known pages
3. Use descriptive anchor text
4. Place important links above the fold
5. Link across related content
6. Update broken internal links regularly
7. Monitor internal link performance in GA4
8. Update links when pages are restructured
9. Link mobile-friendly pages
10. Test internal link navigation

## H. Internal Link Audit Checklist

### Monthly Audit
- [ ] Check for broken internal links (404 errors)
- [ ] Verify anchor text relevance
- [ ] Check that homepage links to all main categories
- [ ] Verify service pages link to related services
- [ ] Ensure blog posts link to relevant service pages
- [ ] Test navigation on mobile devices
- [ ] Check footer link functionality
- [ ] Verify no-follow attributes not overused

### Quarterly Audit
- [ ] Link depth analysis (are pages accessible in 2-3 clicks?)
- [ ] Link ratio analysis (internal vs external links)
- [ ] Anchor text distribution analysis
- [ ] Identify orphan pages (pages with no internal links)
- [ ] Review linking structure for SEO value flow
- [ ] Analyze internal link clicks in GA4
- [ ] Update outdated link destinations
- [ ] Identify missing linking opportunities

### Annual Audit
- [ ] Complete site architecture review
- [ ] Competitive internal linking analysis
- [ ] Full link structure optimization
- [ ] Update keyword-rich anchor text strategy
- [ ] Plan new linking based on new content
- [ ] Archive/remove links to deprecated pages

## J. Internal Linking Impact on SEO

### Benefits
1. **Authority Flow:** Links pass PageRank across pages
2. **Crawlability:** Internal links help Google discover pages
3. **Relevance Signals:** Links indicate page topics
4. **User Navigation:** Helps users find related content
5. **Site Architecture:** Clear structure = better rankings

### Expected Results
- 10-20% improvement in organic visibility (3-6 months)
- Increased internal traffic distribution
- Improved average rank position
- Better user engagement metrics
- Higher conversion rates (users find paths to CTAs)
