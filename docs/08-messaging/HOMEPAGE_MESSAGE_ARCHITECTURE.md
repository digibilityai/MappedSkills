**Status:** **APPROVED — 2026-09-01 (Gate 8, `DEC-013`).** The hero strategic territory *"Judged on the enquiries."* is approved **as a strategic territory, not final homepage copy** — Session 11 determines the actual headline/copy within it.
**Governed by:** `WEBSITE_INFORMATION_ARCHITECTURE.md` §4 · `PAGE_REASON_TO_EXIST_MATRIX.md` §1 · `PAGE_TYPE_CRO_RULES.md` §1 · `docs/09-content-pages/briefs/homepage.md` (all approved, Gates 5–7).

**No homepage copy is written here. No design, no layout, no components, no animation, no visual hierarchy.** This is the message sequence and the strategic territories for the first screen.

---

## 1. The audience fact that determines the sequence

**The homepage is not primarily a cold organic entry point.** It receives a mixed, mostly mid-funnel visitor arriving from a brand search, a referral, a directory listing or a deeper page — and it is deliberately architected **not to rank for service terms**, because every capability page carries its own query family.

**That changes the correct sequence.** A cold problem-led opening is right for a visitor who arrived from a symptom query — which is what `/problems/traffic-but-no-enquiries` is for. A visitor who already has the company's name arrives asking *"what is this, and is it for me?"* **The homepage answers that first, then makes it specific with the problem.**

**So the sequence is derived, not inherited:** proposition → recognition → mechanism → boundary → capabilities → evidence → fit → action. It is **not** the generic problem → outcome → mechanism → capabilities → evidence → methodology → action, and the difference is deliberate.

**One further consequence, and it is unusual:** the accountability boundary and what is not promised sit **high on the page, at block 4** — not in a footnote and not at the end. It is the differentiator, it pre-empts the "every agency says this" objection at the moment it forms, and burying it would waste the only genuinely distinctive thing the page has to say.

## 2. The message sequence

Eight blocks. Each states its message job, what the visitor must understand, the evidence it needs, the objection it resolves and its CTA role. **These are message blocks, not sections, components or screens.**

### Block 1 — Proposition

| | |
|---|---|
| **Message job** | Make the approved commercial proposition legible in seconds, in plain business language |
| **Visitor must understand** | What this firm helps a business accomplish, and that it is about enquiries rather than traffic, rankings or marketing activity |
| **Hierarchy levels** | **1 + 2 together** |
| **Evidence needed** | None. This is a statement of what the firm does, not a claim about results |
| **Objection resolved** | "What is this?" — legibility, not persuasion |
| **CTA role** | **PRIMARY**, available from here on |
| **Must not contain** | Any technique category · any acronym · any industry · any number · any superlative · the prohibited production claim |

### Block 2 — Recognition

| | |
|---|---|
| **Message job** | Turn a generic proposition into a specific one by naming the buyer's situation in their own words |
| **Visitor must understand** | That this firm understands the actual shape of the problem — not found, not converted, not measured — and that it is one problem, not three |
| **Hierarchy level** | **3** |
| **Evidence needed** | None. Recognition, not assertion. **It must describe a situation, never diagnose the reader's** |
| **Objection resolved** | "Is this for a business like mine?" |
| **CTA role** | None |
| **Must not contain** | An accusation ("your site is losing enquiries") · fear framing · a statistic about how many businesses have this problem — **no such figure exists** |

### Block 3 — Mechanism

| | |
|---|---|
| **Message job** | Show how the outcome is produced: capture demand → convert it into enquiries → measure the whole chain, **as connected parts with the joins owned** |
| **Visitor must understand** | That the parts are connected, that fixing one alone often changes nothing they can observe, and that the joins between them are somebody's job here. **Not that they must buy all three** — scope is decided per client, and the engagement model is owner-blocked |
| **Hierarchy level** | **4** |
| **Evidence needed** | The published method, linked. **This is where the chain is better shown than described** |
| **Objection resolved** | "Why not hire separate specialists?" and "This is just SEO with extra words" |
| **CTA role** | **PROOF** — an offer, never a gate |
| **Must not contain** | A branded framework name · a stage list that reads as three services · a promise about speed |

### Block 4 — The accountability boundary

| | |
|---|---|
| **Message job** | State what MappedSkills owns, what it reports on using client data, and what it does not promise — **as a position, not an apology** |
| **Visitor must understand** | Accountability runs to the qualified enquiry; revenue is reported from their own close data; some things cannot be attributed and will be labelled that way |
| **Hierarchy level** | **2**, at full strength |
| **Evidence needed** | The method, and the attribution-limits section it links to |
| **Objection resolved** | "Every agency says this" · "Can you guarantee results?" · "Will you promise revenue or rankings?" |
| **CTA role** | **PROOF** |
| **Must not contain** | Hedging language · legalese · a disclaimer register · an apology for the limit |

### Block 5 — Capabilities, subordinated

| | |
|---|---|
| **Message job** | Name the capabilities so a visitor who arrived thinking "SEO" or "Google Ads" sees relevance — and route them to the right page |
| **Visitor must understand** | Which disciplines are involved, where each sits in the chain, and that none of them is what the company *is* |
| **Hierarchy level** | **5** |
| **Evidence needed** | None at this block. Each capability page carries its own |
| **Objection resolved** | "Do you actually do the thing I came here for?" |
| **CTA role** | **CONTEXTUAL** — routing to `/services` and the capability pages |
| **Must not contain** | Equal-weight service cards · a service menu · six capabilities presented as six pillars · AI search given disproportionate space · any capability promoted into the proposition |

### Block 6 — Reason to believe

| | |
|---|---|
| **Message job** | Give the visitor something checkable, and be specific about what exists rather than gesturing at credibility |
| **Visitor must understand** | The method is published, MappedSkills measured its own AI visibility and published the result including a zero, it diagnosed and published its own site's failures, and real named people did the work |
| **Hierarchy level** | **6** |
| **Evidence needed** | `/how-it-works` · both research entries · named people. **And nothing else, because nothing else exists** |
| **Objection resolved** | "Why should I trust you without dozens of case studies?" |
| **CTA role** | **PROOF** |
| **Must not contain** | **No logo wall. No client count. No testimonial. No rating. No metric. No "trusted by". No case-study CTA.** No implication that results exist and are simply not shown |

### Block 7 — Fit

| | |
|---|---|
| **Message job** | Let a good-fit buyer recognise themselves and a poor-fit buyer leave without enquiring |
| **Visitor must understand** | This is for considered-purchase businesses where one enquiry is worth real money and demand already exists — and it is not for businesses needing demand invented, or expecting guaranteed outcomes |
| **Hierarchy level** | **3**, from the qualification side |
| **Evidence needed** | None. Fit criteria, stated plainly |
| **Objection resolved** | "Am I too small / too large / the wrong kind of business?" and, silently, the price question |
| **CTA role** | **CONTEXTUAL** — to `/pricing` and `/services` |
| **Must not contain** | Disparagement of the businesses it is not for · a revenue, headcount or turnover threshold — **`ICP.md` §9 deliberately sets none** |

### Block 8 — Action

| | |
|---|---|
| **Message job** | Make the next step obvious, low-friction and honest about what happens |
| **Visitor must understand** | They can write or they can book, both reach the same place, and direct contact is available now |
| **Hierarchy level** | **7** |
| **Evidence needed** | None |
| **Objection resolved** | "What actually happens if I make contact?" |
| **CTA role** | **PRIMARY**, both surfaces. **DIRECT** always visible |
| **Must not contain** | A second competing goal · a response-time promise · manufactured urgency · a "free" framing before the entry-offer decision |

## 3. What must never appear on the homepage

Carried from the approved brief and made explicit as messaging rules.

1. **No technique category as the company's identity** — not SEO, AI search, GEO, AEO, LLMO, CRO, performance marketing or marketing automation.
2. **No industry framing.** MappedSkills is not a manufacturing agency, and no company-level page may read as though the beachhead were settled.
3. **"300%+ ROI", "₹100Cr+", "₹10Cr+"** — and note that **the current production homepage title carries the first of these and must change.** It is verified as being redistributed by Google AI Mode and Perplexity as fact about the company.
4. **No logo wall, client count, testimonial, rating, review count or award.**
5. **No metric of any kind** — no traffic, ranking, enquiry, conversion or AI figure.
6. **No guarantee**, of anything.
7. **No AI Visibility Score, AI rank or blended AI figure.**
8. **No superlative.**
9. **No AI hype block.** AI search does not appear in the first screen and gets no disproportionate section.
10. **No service-term ranking attempt.** The homepage's query surface is brand and entity only.

## 4. Above-the-fold — five strategic message territories

**These are territories, not headlines.** Each has a core thought, a direction for the headline, a direction for the supporting line, why it fits and what it risks. **They are meaningfully different arguments, not five rewrites of one sentence.**

**§5 stress-tests all five against buyer comprehension and makes the recommendation.** The territories themselves are unchanged from the original Session 10 set; **no additional territory was invented.**

### Territory 1 — The Accountable Enquiry *(reframed — see §5)*

**Core thought:** most suppliers are judged on the activity. MappedSkills is judged on the enquiries the business actually gets, and says where that stops.

**Headline direction:** a plain statement of what the firm is judged on, using the word "enquiries" rather than "leads".

**Supporting-line direction:** the boundary in one sentence — owned to the qualified enquiry, reported through to revenue on the client's own data, and honest about what cannot be attributed.

**Why it fits:** it states the approved outcome without translation; its differentiator is true today, unclaimed by every competitor examined, and defensible with no client result at all; and it holds Level 1 without borrowing a capability.

**Risk:** **"accountable" is a governance word before it is a commercial one**, and the territory as originally named was strategically elegant rather than buyer-readable. §5 resolves this by reframing the expression while keeping the content.

### Territory 2 — Demand You Already Have

**Core thought:** there are buyers for this business already. The loss happens between them and the business, not in the market.

**Headline direction:** about reaching buyers who already exist, rather than manufacturing interest.

**Supporting-line direction:** name where it is lost — before you are found, on the page, in the enquiry path, or invisibly in the measurement.

**Why it fits:** it is the clearest expression of demand *capture*, which is the real ICP boundary; it disqualifies the wrong buyer immediately; and it sets up the four loss zones the rest of the site uses.

**Risk:** it asserts something about the reader's market that MappedSkills has not verified, and it can read as blaming the reader for a loss they did not know they had. **It must also not imply that being findable in search is what makes a business eligible** — demand may be reached through paid as well as organic.

### Territory 3 — Measured, Not Claimed

**Core thought:** the difference is not what is promised. It is that the result can be checked — including the parts that cannot be.

**Headline direction:** lead with checkability and the refusal to guarantee.

**Supporting-line direction:** what is measured, and the plain statement that what cannot be attributed is labelled rather than smoothed over.

**Why it fits:** it is the most defensible position in a category of unfalsifiable promises, and MappedSkills can demonstrate it today by publishing its own measured zero.

**Risk — evidenced, not hypothetical.** Session 04 tested measurement honesty as a proposition and concluded it is **not one**: a business owner looking for enquiries does not have a methodology problem, and the surrounding search demand is for free checkers, not rigour. **Leading with it risks answering a question nobody asked.**

### Territory 4 — Where The Enquiries Go Missing

**Core thought:** name the symptom the buyer already recognises — traffic arrives, enquiries do not, and nobody can say why.

**Headline direction:** the symptom, in the buyer's own words.

**Supporting-line direction:** it is one of four things, and the first job is finding out which.

**Why it fits:** it is the most recognisable buyer language anywhere in this programme, on the most winnable SERP observed, and it converts the proof deficit into a diagnostic posture.

**Risk:** it is **the problem page's job**, it narrows the company to a conversion firm, and it presumes the reader already has traffic — which is not true of every approved buyer.

### Territory 5 — One System, Not Three Suppliers

**Core thought:** a break can fall between the search work, the page, the form and the measurement, and where responsibility is split those joins can belong to nobody.

**Headline direction:** single responsibility across the whole path to the enquiry.

**Supporting-line direction:** each part was done correctly and the enquiry still did not arrive.

**Why it fits:** it counters every competitive alternative at once, and MappedSkills has a genuine worked example in its own site diagnostic.

**Risk — and it is now larger than it was.** It argues about **supplier structure**, which is second-order for an owner who wants the phone to ring; worded loosely it drifts toward "full-service", a rejected positioning; and **the orchestrator correction pass explicitly prohibits claiming that MappedSkills replaces three suppliers.** The territory's name asserts precisely that.

## 5. Hero stress test *(added 2026-09-01, orchestrator correction pass 3)*

**The test.** Not "is this strategically correct?" — all five are. The test is **what a real buyer understands in about five seconds**, before they have any interest in the strategy behind it.

**Two constraints on the outcome, both from the correction brief:**
- **The approved outcome phrase "measurable qualified enquiries" must not simply become a slogan.** A hero that repeats the strategic formulation has translated nothing.
- **A buyer must understand the commercial idea before appreciating the strategic sophistication.** Cleverness is not the objective.

**Judged on seven criteria:** buyer comprehension · commercial relevance · differentiation · defensibility with today's proof · ability to bridge search + conversion + measurement · avoidance of agency jargon · ability to support the approved IA without turning MappedSkills into an SEO agency.

### Territory 1 — The Accountable Enquiry

| | |
|---|---|
| **Underlying buyer insight** | *"I have paid several suppliers who all showed me their part going up, and the phone did not ring any more than before. Nobody was ever on the hook for the thing I actually wanted."* — a real and widely felt commercial grievance |
| **Understood in ~5 seconds** | **Weakly, as named.** "Accountable" is a governance and audit word. A business owner reads "accountability" as being about responsibility and blame, not about enquiries arriving. **The abstraction lands before the commercial idea does** |
| **Principal weakness** | **The name and register, not the content.** "The Accountable Enquiry" is an internally elegant construction: it is a noun phrase describing a *property of a concept*, not a statement about the reader's business. It also sits one step away from restating "measurable qualified enquiries" — the exact sloganisation the brief warns against |
| **Illustrative headline direction** | *"We're judged on the enquiries you get — not on the traffic."* — the same idea in ordinary words, with the contrast that makes it mean something |

**Scores well on:** commercial relevance · differentiation · defensibility *(it is a statement of what the firm holds itself to, not a result claim)* · bridging all three disciplines *(the enquiry is downstream of all of them)* · IA support *(it names no technique)*.
**Scores badly on:** buyer comprehension, as originally expressed.

### Territory 2 — Demand You Already Have

| | |
|---|---|
| **Underlying buyer insight** | *"There are people who want what I sell. They are buying it from someone."* |
| **Understood in ~5 seconds** | **Strongly.** It is concrete, it is about the reader's market, and it needs no marketing vocabulary |
| **Principal weakness** | It **asserts something about the reader's market that has not been verified**, and it can read as an accusation. It also does not, on its own, reach conversion or measurement — it is an acquisition idea, and used alone it would let the site drift toward being read as a search firm |
| **Illustrative headline direction** | *"The buyers are already out there. Some of them never reach you."* **[Corrected 2026-09-01, Gate 9A, `DEC-015`. Original: "Most of them never reach you" — an unsupported second-person quantity claim, flagged by this document's own "Principal weakness" row above and corrected on that basis. No new positioning idea introduced.]** |

**Scores well on:** buyer comprehension · commercial relevance · jargon avoidance.
**Scores badly on:** bridging search + conversion + measurement · differentiation *(many agencies say a version of this)*.

### Territory 3 — Measured, Not Claimed

| | |
|---|---|
| **Underlying buyer insight** | *"Every agency's report made them look good and told me nothing I could check."* |
| **Understood in ~5 seconds** | **Understood, but as a process attribute rather than a commercial offer.** The reader grasps "they measure things carefully" and does not yet know what they would get |
| **Principal weakness** | **Evidenced against.** Session 04 found measurement honesty is a proof principle, not a proposition — the buyer does not have a methodology problem. As a hero it answers a question nobody asked, and it makes the firm sound like an analytics practice |
| **Illustrative headline direction** | *"Every number we give you, you can check. Including the ones we can't give you."* |

**Scores well on:** differentiation · defensibility.
**Scores badly on:** commercial relevance · buyer comprehension of the *offer*.

### Territory 4 — Where The Enquiries Go Missing

| | |
|---|---|
| **Underlying buyer insight** | *"Visits are up. Enquiries are not. I don't know why."* |
| **Understood in ~5 seconds** | **Strongest of the five.** Instant recognition, in the buyer's own words, with no translation |
| **Principal weakness** | **It is another page's job**, and using it here sets the homepage competing with `/problems/traffic-but-no-enquiries` for one message. It also **presumes the reader already has traffic**, which is not true of every approved buyer, and it narrows the firm to conversion — losing the capture half of the proposition on the one page that must carry the whole of it |
| **Illustrative headline direction** | *"Traffic up, enquiries flat? It's one of four things."* |

**Scores well on:** buyer comprehension · jargon avoidance.
**Scores badly on:** IA support *(cannibalises the problem page)* · scope *(narrows the company)*.

### Territory 5 — One System, Not Three Suppliers

| | |
|---|---|
| **Underlying buyer insight** | *"My SEO person, my web developer and whoever set up my analytics have never spoken to each other."* |
| **Understood in ~5 seconds** | **Understood — and frequently as the wrong thing.** "One system, not three suppliers" reads to many buyers as *"they do everything"*, which is the full-service positioning the strategy rejects |
| **Principal weakness** | **It is now also prohibited as stated.** The orchestrator correction pass bars claiming that MappedSkills replaces three suppliers, and the territory's name asserts exactly that. Its surviving idea — *the joins between the parts are somebody's job* — is a genuine supporting proposition (`VALUE_PROPOSITION_ARCHITECTURE.md` S1) and a second-order concern for an owner who wants the phone to ring |
| **Illustrative headline direction** | *"The gap between your search work and your enquiry form belongs to someone here."* |

**Scores well on:** differentiation · competitive defence.
**Scores badly on:** buyer comprehension *(misreads as full-service)* · commercial relevance · compliance with correction pass 2.

### What the stress test found

**No territory passes on all seven criteria, and the gap is not where it looked.**

- **Comprehension and commercial scope trade off against each other.** The two territories a buyer understands instantly — 2 and 4 — are the two that narrow the firm or belong to another page. The two with the right scope — 1 and 5 — are the two expressed in strategist's language.
- **Territory 3 is settled by existing evidence** and is not a hero.
- **Territory 5 is now partly prohibited** by correction pass 2 and cannot be recommended as named.
- **Territory 1's content survived the test; its expression did not.** That is the actual finding, and it is a correction rather than a defence: the concept is right, the words were written for a strategy document.

**No strategic gap was revealed**, so no sixth territory is invented. **The correct action is the one the brief explicitly permits: reframe Territory 1 into buyer language.**

## 6. Final hero territory recommendation

### Territory 1, reframed: **"Judged on the enquiries"**

**Renamed from "The Accountable Enquiry". The strategic content is unchanged; the register is not.**

| | |
|---|---|
| **Core thought** | Most suppliers are judged on their own part going up. MappedSkills is judged on the enquiries the business actually gets — and can show where they came from |
| **What the visitor understands in ~5 seconds** | *"They're on the hook for the enquiries, not the traffic — and they'll show me the evidence."* A commercial idea, not a strategic one |
| **Headline direction** | A plain statement of what the firm is judged on, set against what other suppliers report. **Ordinary words. No "measurable qualified enquiries", no "accountability", no "outcome"** |
| **Supporting-line direction** | Territory 2's concrete opening does the acquisition work — that buyer demand for this business already exists and some of it never arrives — followed by the boundary in one clause: owned to the enquiry, revenue reported from the client's own data, and honest about what cannot be attributed. **[Corrected 2026-09-01, Gate 9A, `DEC-015`; see the illustrative-headline correction above.]** |
| **Why this one** | It is the only formulation that scores acceptably on **all seven** criteria at once, and the reframing fixes the single criterion the original failed |

**Against the seven criteria:**

| Criterion | Verdict |
|---|---|
| **Buyer comprehension** | **Fixed by the reframe.** "Judged on" is ordinary business language; "accountable" was not |
| **Commercial relevance** | **High.** Enquiries are the thing the buyer wants, named as the thing the supplier is measured by |
| **Differentiation** | **High and honest.** It is a statement about what MappedSkills holds itself to — unclaimed by every competitor examined — not a claim about results |
| **Defensibility with today's proof** | **Full.** It requires no client result. What it promises is a standard of accountability and a published boundary, both of which exist |
| **Bridges search + conversion + measurement** | **Yes, structurally.** An enquiry is downstream of all three, so the hero implies the whole chain without listing disciplines |
| **Jargon avoidance** | **Yes**, once "accountable" and "outcome" are removed. The remaining vocabulary is enquiries, traffic and evidence |
| **Supports the IA without becoming an SEO agency** | **Yes.** It names no technique, so `/seo` and `/ai-seo` can confirm their search intent freely beneath a company message that is not a category |

**What it must not become:** a restatement of "measurable qualified enquiries" · a promise of a number · a claim that all three parts are always bought · a boast about accountability rather than a statement of it.

**Territories 2, 3, 4 and 5 are not discarded — they are placed:**

| Territory | Where its argument belongs |
|---|---|
| **2 — Demand You Already Have** | The **supporting line beneath the recommended hero**, and the opening of `/services` |
| **3 — Measured, Not Claimed** | Homepage **block 4** and **block 6**, and `/how-it-works` at full strength |
| **4 — Where The Enquiries Go Missing** | **`/problems/traffic-but-no-enquiries`**, where it is the page's whole job |
| **5 — One System, Not Three Suppliers** | Reframed as supporting proposition **S1**, *"the joins between the parts are somebody's job"* — never as a claim to replace three suppliers |
