## 1. The risk this document exists to remove

Session 13 stated that **F1 is one object across eight routes**. That is conceptually right and it created a real risk the orchestrator identified:

> **A figure that appears on eight of twenty-two routes stops being an explanation and starts being a signature.** The moment it is everywhere it becomes a brand device — and **a brand device shaped like a path is a funnel** (B24, B2).

**Correction recorded.** Applying the taxonomy below, **F1 appears on six unconditional routes, not eight**, and **only three of those carry the full figure.** `/ai-seo`, `/google-ads` and `/social-media-ads` are reclassified to **NONE**; `/lead-generation` is added as a **STATE**.

**This is a correction to Session 13's own claim, not a change to approved creative direction.** `19` names the routes F1 *may* appear on; it does not require it on any of them, and it states the governing rule plainly: **a figure replaces the prose that carried the structure — it does not sit beside it as an illustration.**

## 2. The four usage classes

| Class | What it is | When it is correct |
|---|---|---|
| **A — FULL RUN** | The complete object: discovery and source → landing → interaction → enquiry → qualified enquiry → opportunity and revenue from the client's own data, with the accountability boundary drawn, unmeasured stretches dashed, at least one unattached arrival, and intervention marks | **Only where the whole chain is genuinely the page's subject** |
| **B — PARTIAL RUN** | One named segment, with the remainder recessive or absent — **not the whole figure shrunk.** Segment categories: **discovery** · **paid acquisition** · **landing/enquiry** · **attribution** | Where the page's subject is one part of the chain and locating it inside the whole is the argument |
| **C — STATE CHANGE** | The same conceptual object shown in a changed condition: an intervention, a break, an unattributed arrival, a measured boundary, or a repaired state | Where the page's subject is a *property* of the chain rather than the chain itself |
| **D — NONE** | The figure does not appear | **Where it adds nothing.** The default for any page with its own justified figure |

**The governing rule: D is the default.** A route earns A, B or C by argument. **F1 is not applied for consistency, recognition or visual rhythm.**

## 5. What the run must never become

Carried from B24 and B2, restated as checkable prohibitions for the wireframe pass.

| Prohibited | Why |
|---|---|
| **A logo, mark or signature** | It stops explaining and starts branding |
| **A background, watermark or texture** | Ambient use is the named failure mode |
| **A section divider or rule motif** | The dashed line means an epistemic gap on this site (B23); diluting it makes the honest device unreadable |
| **A page-transition, loader or header element** | B24, explicitly |
| **A repeated visual signature across pages** | The reason for the D default |
| **A taper of any kind** | It becomes a funnel. **The distance between "the run" and "a funnel" is one designer's decision about tapering** |
| **Per-stage colours** | It becomes a transit map, and a transit map of a marketing process is a funnel with better graphics |
| **A branded name** | B18 binds figure labels as much as copy |

## 6. Rules for PARTIAL and STATE renderings

**PARTIAL**
1. It is **a segment shown at full legibility**, not the whole figure reduced until only one part is readable.
2. The remainder of the chain is **recessive or absent** — it is never drawn at equal weight, because that is the full figure again.
3. **The dashed stretches, the boundary and the unattached arrival remain honest within whatever is shown.** A partial view must not accidentally show a fully-measured chain.
4. It carries its own text equivalent for the segment shown.

**STATE**
1. It is **the same object in a changed condition**, and the reader must be able to recognise it as such.
2. **A state is never a second figure on a page that already carries the run.** `/` Block 4 is a state on Block 3's instance.
3. **`changed` states are state pairs, never metric pairs**, dated, and used on MappedSkills' own property until a client gives written permission.

**Both**
- Complete and readable statically, with no interaction and no motion.
- A genuine vertical form at narrow widths — never a scaled-down horizontal one, and **never horizontal page scrolling**.
- Labels on the figure as real text; **no text rendered as an image**.
